EXCLUSIONS

Exclure :

- événements CCI ;
- événements destinés exclusivement aux collégiens ;
- événements destinés exclusivement aux lycéens ;
- événements exclusivement avant le supérieur ;
- cabinets privés de recrutement ;
- informations non vérifiables ;
- événements commerciaux sans rapport avec les objectifs ;
- doublons.

ATTENTION

La présence des mots "lycéen", "lycée" ou "collège" ne suffit pas à exclure un événement.

Un événement mixte reste pertinent lorsqu'il comporte une composante enseignement supérieur.

RÈGLE DE VÉRIFICATION

Ne jamais inventer une information.

Si une donnée n'est pas vérifiable :
mettre la valeur "À vérifier".

Si l'événement est clairement hors périmètre :
mettre "Non pertinent".

RÈGLE DE SOURCE

Conserver l'URL de la source.

Privilégier les sources officielles :
- établissements ;
- universités ;
- écoles ;
- collectivités ;
- organisateurs ;
- plateformes événementielles ;
- médias locaux fiables.

Ne pas utiliser les cabinets privés de recrutement comme sources finales.

RÈGLE HISTORIQUE

Lorsqu'un événement est passé, rechercher une éventuelle édition suivante.

Conserver l'historique.

RÈGLE APEC

Présence APEC :

OUI uniquement si une source permet de l'établir.

NON si aucune présence connue n'est trouvée.

À VÉRIFIER si l'information est ambiguë.

Ne jamais déduire une présence APEC sans source.

RÈGLE CONTACT

Lorsque des informations professionnelles publiques sont disponibles :

- nom ;
- fonction ;
- établissement ;
- email professionnel ;
- téléphone professionnel ;
- URL source.

Ne jamais inventer de coordonnées.

SORTIE

Produire une donnée par champ.

Ne jamais mélanger plusieurs informations dans une même cellule.

Aucune spéculation.
